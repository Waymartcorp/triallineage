# TrialLineage Support Framing

## Purpose

This file defines how to explain TrialLineage's value to donors, supporters, and public-interest science funders.

## Core message

TrialLineage is not just a collection of manually written science stories. It is being built as a repeatable public-science system.

## Preferred framing

TrialLineage identifies concrete clinical/FDA-type endpoints, applies consistent evidence criteria, traces the science backward, preserves source trails, labels uncertainty, and produces reviewable public explanations.

## Avoid saying

- AI writes science pages automatically
- Fully autonomous medical claims
- No human review needed
- Automated scientific truth

## Use instead

- Criteria-driven
- Source-tracked
- Confidence-labeled
- Human-reviewable
- Repeatable
- Transparent
- Public-interest science infrastructure

## Suggested donor-facing paragraph

"TrialLineage is designed as a repeatable public-science engine. Each lineage begins with a concrete clinical endpoint — a Phase 1–3 trial, FDA approval, or regulatory milestone — and applies the same structured process: identify the endpoint, summarize the clinical event, trace backward through the enabling science, surface key branch points and failed paths, connect related concepts, and preserve source trails and uncertainty labels. The goal is not to replace scientific judgment. The goal is to make serious public science explanation more scalable, transparent, and durable."

## Strategic donor point

Donors may value the automation because it allows TrialLineage to scale beyond one-off science writing while still using transparent criteria, source trails, confidence flags, and human review.
